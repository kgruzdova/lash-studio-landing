ДЕМО-СТРАНИЦА

Конфиденциальность демонстрационной формы

Этот сайт показывает пример оформления студии наращивания ресниц. Имя мастера, контакты, адрес, цены, акция и отзывы — демонстрационные данные. Часть изображений создана с помощью ИИ.

Какие поля есть в форме

В форме предусмотрены имя, телефон, желаемый эффект, дата, время и необязательный комментарий. Для знакомства с формой используйте вымышленные данные.

Что происходит при отправке

В текущем демо-режиме значения проверяются только в браузере. Заявка не отправляется на сервер, не записывается в таблицу и не сохраняется в хранилище браузера. После успешной проверки форма очищается. Реальная запись на процедуру не создаётся.

Внешние ссылки и ресурсы

Основная страница загружает шрифты Google Fonts. При переходе по ссылкам социальных сетей открываются сторонние сайты с собственными условиями обработки данных. Контактные ссылки на этом макете приведены только для примера.

Перед запуском студии

Владелец сайта должен заменить демо-контакты своими, подготовить политику для фактического порядка обработки данных и подключить реальную отправку заявок. Эта страница описывает работу текущей демонстрации.

Версия демонстрации: 7 октября 2026 года.
